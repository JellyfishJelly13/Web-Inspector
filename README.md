# Jelly Web Inspector

A lightweight, read-only web inspector that can be embedded into any website with a single script tag.

## Usage

Add the following snippet to your HTML:

```html
<script src="https://jelly-web-inspector.vercel.app/index.js"></script>
```

## Features

- **Lightweight** — easy to integrate into existing websites.
- **Read-only** — inspect without editing website content.
- **Embeddable** — works through a simple script include.
